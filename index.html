Ticketum Backup

Private, administrator-operated backups for Ticketum.

Ticketum Backup is an administrative tool designed to help the owner of Ticketum protect its PostgreSQL database and prepare for recovery. It is not a public file-storage service or a Google sign-in feature for theatre customers.

Implementation status: the backup automation has been prepared. Google Drive authorization, uploads and the complete cloud backup process have not yet been validated. This website does not mean that scheduled backups are running.

Why Google Drive access is requested

With the owner's permission, the tool is designed to create and manage its own backup folders and files using the Google Drive API. It requests only https://www.googleapis.com/auth/drive.file, which covers files created by the application or explicitly made available to it, rather than general access to all files in the account.

How backups are protected

The prepared workflow encrypts PostgreSQL backups with AES-256-GCM before uploading them. It checks uploaded bytes using SHA-256 and retains a combined set of 7 daily, 4 weekly and 3 monthly recovery points. Recovery must be tested separately; a successful upload alone does not establish recoverability.

Your control

The Google account owner authorizes the connection and can revoke it at any time in Google Account settings. Access is used for backup management, not advertising or sale of Google user data.
